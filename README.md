XENOR Social Platform

Production Cloudflare Worker project.

Includes:
- User registration and login
- Profiles
- Friend requests
- Follow / unfollow
- Posts, likes and comments
- Stories and Reels
- Messaging
- Notifications
- Market
- Academy
- Services and Orders
- Reports and blocking
- Admin dashboard
- Cloudflare D1 database
- Cloudflare R2 media storage
- Android PWA

Deployment:
Cloudflare Workers + D1 + R2

Important:
Configure the D1 database binding as DB.
Configure the R2 bucket binding as MEDIA.
